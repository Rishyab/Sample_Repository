# Software Testing & Quality Assurance

This repository contains resources and materials for the Software Testing & Quality Assurance lecture. It aims to provide students with an understanding of the principles, methodologies, and tools used in software testing. Topics covered include:

- Introduction to Software Testing
- Types of Testing (Manual, Automated, Unit, Integration, etc.)
- Testing Frameworks and Tools
- Quality Assurance Practices
- Test Planning and Strategy

Feel free to explore the materials and contribute to the discussion!
